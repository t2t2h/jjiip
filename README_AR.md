# Twix Control — Theos Project

مشروع Theos بواجهة عائمة متحركة لمراقبة زمن استجابة HTTPS، مع شريط إعداد محاكاة محلي.

## ما الذي يعمل فعلياً؟
- زر عائم قابل للسحب.
- لوحة داكنة بتأثير بنفسجي وحركة فتح/إغلاق.
- زر CHECK يقيس زمن استجابة طلب HTTPS إلى Cloudflare trace endpoint.
- شريط Lag يضبط قيمة ملف الاختبار ويعرضها.
- `TWXDelayGate.h/.m` مساعد اختياري تدمجه داخل **لعبتك/تطبيقك أنت** لتأخير callback أو إسقاطه عشوائياً أثناء الاختبارات.

## حدود مهمة
- قيمة Lag في واجهة الـ tweak هي معاينة إعداد فقط؛ لا تغيّر مرور الشبكة العام ولا تسبب lag للألعاب الأخرى.
- `TWXDelayGate` يعمل فقط عندما تستدعيه بنفسك من كود تطبيقك. لا يحقن فقد حزم أو يعطّل اتصال تطبيقات الغير.
- قياس HTTPS ليس ICMP ping؛ هو زمن طلب واستجابة إلى خادم محدد، ويتأثر بالإنترنت وTLS والخادم.

## البناء
تحتاج macOS أو بيئة Theos جاهزة مع SDK وأداة تغليف Debian.

```sh
git clone <YOUR_REPOSITORY_URL>
cd TwixControl
make package
```

إذا كانت بيئة Theos لا تستخدم إعدادات rootless، جرّب:
```sh
make package THEOS_PACKAGE_SCHEME=rootless
```

الناتج يكون داخل مجلد `.theos/packages/` بصيغة `.deb`.

## التثبيت
انقل ملف `.deb` إلى جهاز الاختبار وثبّته عبر مدير الحزم المتوافق مع بيئة الجلبريك. أعد تشغيل SpringBoard عند الحاجة.

## ملاحظات توافق
- الكود يستخدم UIKit وLogos، ويحتاج بيئة Theos متوافقة مع إصدار iOS المستهدف.
- فلتر `Bundles = ("*")` يطلب الحقن في كل الحزم؛ دعم wildcard يعتمد على أداة الحقن/مدير الجلبريك. إذا لم يظهر الزر في التطبيقات، اختبر أولاً بحقن الحزمة في تطبيق اختبار تملكه بإضافة Bundle ID صريح إلى `TwixControl.plist`.
- لا يمكن ضمان التوافق مع كل إصدار iOS أو كل أداة حقن دون بناء وتجربة على الجهاز الفعلي.
